# GSE263850 benchmark integration

Goal: connect all six untreated GRCh38 samples and the 813 published DMRs
to a reproducible, sequential six-package real-data benchmark.

The user authorized dataset integration, specified DSS's multi-factor
smoothed model and requested close equivalents for other tools. Implement
inline. Existing GSE64177 inputs, runners and results remain unchanged.

- [ ] Add a dataset adapter with tested stale-path repair, WT/control and
  KO/treatment mapping, integer-count/coordinate/coverage validation,
  already-collapsed strand handling, and comma-decimal paper parsing.
- [ ] Add paper-aligned runners. DSS uses DMLfit.multiFactor(~group,
  smoothing=TRUE, span=500), DMLtest.multiFactor(coef=2), and callDMR with
  p.threshold=1e-5, delta=0, minlen=50, minCG=3, dis.merge=100, pct.sig=.5.
  Record its native effective merge distance of 50. Epykit retains the
  accepted region correction; align smoothing, raw seed and geometry.
  MethylKit uses native CpG inference followed by documented raw-p region
  aggregation. BSmooth, dmrseq and DMRcate keep their native statistical
  methods and record unsupported or approximate parameter mappings.
- [ ] Add a reusable real_benchmark.py CLI with prepare/run/status/compare,
  immutable source/input provenance, no memory/time caps, failure isolation,
  and sequential timing. Compare with the paper at any/50%/80% reciprocal
  overlap using both coverage and one-to-one precision/recall; annotate
  using supplied GRCh38 refGene, never the old hg19 TxDb.
- [ ] Verify adapters and runner integration on small six-sample fixtures,
  inspect independent review, then launch the full six-tool study in tmux.

Coverage is at least five reads per site according to downloaded GEO SOFT.
Processed BED counts combine both strands; supplied COV positions are
BED starts plus one. Reference comparison is a published-list benchmark,
not independently established biological ground truth. All six samples
derive from one parental iPSC line; no donor pairing is invented.

Evidence: development/gse263850_20261009/metadata/verified_geo_metadata.json.
Paper: doi:10.1038/s41380-025-03040-x, supplied supplementary table 5.
